**Title:** Store_It - A Cloud-Based Storage Management System

**Problem Statement:**  
Managing digital files efficiently is crucial in both personal and professional spaces. Traditional storage solutions often lack real-time collaboration, seamless accessibility, and a user-friendly interface. Store_It aims to provide a robust cloud-based storage management system similar to Google Drive, offering secure file storage, sharing, and management functionalities.

**Types of Diagrams Used:**

- **Use Case Diagram** – To define system interactions and user functionalities.
- **Entity-Relationship Diagram (ERD)** – To model data relationships within the database.
- **Component Diagram** – To visualize the structure of the application.
- **Sequence Diagram** – To represent user interactions with system operations.
- **Deployment Diagram** – To showcase how the application is hosted and accessed.

**Methodology:**  
The development follows the **Agile Methodology**, ensuring iterative improvements, feedback-driven enhancements, and flexibility in feature development. The process includes requirement gathering, UI/UX prototyping, backend and frontend development, testing, and deployment.

**Techniques:**

- **State Management** using React Context API
- **Authentication & Authorization** via Appwrite’s user authentication
- **Data Storage & Retrieval** using Appwrite’s Database & Storage APIs
- **File Upload & Management** with Appwrite’s file storage
- **API Integration** for seamless client-server communication
- **Performance Optimization** by implementing lazy loading, caching and Debouncing

**Technologies:**

- **Frontend:** React.js, Next.js (for SSR & Routing)
- **Backend & Storage:** Appwrite (for authentication, database, and storage)
- **UI/UX Design:** Figma
