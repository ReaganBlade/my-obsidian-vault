The widely used OAuth standards include:

1. **OAuth 2.0** – The most widely adopted standard for authorization, used in web and mobile apps.
    
2. **OAuth 2.1** – An updated version of OAuth 2.0 that simplifies security best practices by removing implicit flow and password grants.
    
3. **OpenID Connect (OIDC)** – Built on OAuth 2.0, it adds authentication to provide user identity verification.
    
4. **JWT (JSON Web Token)** – Often used with OAuth 2.0 for secure token-based authentication.
    
5. **PKCE (Proof Key for Code Exchange)** – An OAuth 2.0 extension that enhances security, especially for mobile and single-page apps.
    
6. **SAML (Security Assertion Markup Language)** – Though not OAuth-based, it is used for Single Sign-On (SSO) alongside OAuth in enterprise environments.
